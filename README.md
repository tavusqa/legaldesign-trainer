# Аренда CLM — юридический тренажёр (legal design в спорах из аренды)

Тренажёр для студентов в духе спецпроекта Право.ru (legaldesign.pravo.ru):
одна непрерывная скролл-лента — интро → выбор дела → фабула и позиции сторон
(блоки появляются и сменяются только прокруткой, назад отматываются) →
выбор позиции (до него физически не добраться, не прочитав фабулу) →
сборка процессуального документа (к каждому доводу — визуализация) →
готовый документ → решение суда с разбором. Никакой отправки данных:
финал — документ и вердикт с правовыми позициями.

Четыре спора · две стороны в каждом · три довода · три варианта визуализации
= **72 схемы**, все генерируются кодом.

## Запуск

Нужен http-сервер — модули читают соседние файлы, `file://` Chrome не пустит:

```
cd legaldesign-demo && python3 -m http.server 8731
# затем http://127.0.0.1:8731/
```

Статика целиком: ни сборки, ни зависимостей, ни CDN — принцип 3 из `../CLAUDE.md`.
Работает как есть на GitHub Pages.

## Файлы

| Файл | Что делает |
|---|---|
| `index.html` | Каркас: главы-скроллы (интро, фабула), секции (дела, позиция, сборка, документ, решение) |
| `css/style.css` | Судебная палитра: тёмно-синий зал, латунь весов, пергамент документов; шрифты системные |
| `js/scrolly.js` | Движок покадровой анимации по скроллу, ~110 строк. Ключевые кадры считаются от начала «главы», а не от верха страницы — главы строятся динамически |
| `js/viz.js` | Семь параметрических рендереров SVG: `timeline`, `waterfall`, `chain`, `bars`, `split`, `table`, `list` |
| `js/cases.js` | **Всё содержание**: споры, стороны, доводы, варианты, разборы, исходы, правовые позиции |
| `js/app.js` | Движок тренажёра: сцены интро (здание суда, весы, документ), три стиля фабулы (cards/focus/slides), сброс дела при возврате, игра, документ, вердикт |
| `deploy.sh` | Публикация на Pages с версионированием ассетов |

`app.js` не знает ни одного спора по имени — новый предмет спора добавляется
только правкой `cases.js`.

## Как устроен скролл (главное отличие от кликовых экранов)

Глава — секция высотой N×100vh со `position:sticky`-сценой; `scrolly.js`
интерполирует прозрачность/сдвиг слоёв по позиции прокрутки. Состояние —
чистая функция scrollY, поэтому обратная прокрутка «бесплатно» отматывает
всё назад. Окна видимости блоков перекрываются — пустых экранов между
блоками нет. Интерактив (выбор дела, позиции, схем) лежит в обычных
секциях ПОСЛЕ глав: до выбора позиции нельзя добраться, не прокрутив фабулу.

## Стили фабулы (шаг 2) — данными

Поле `story` у дела в `js/cases.js`:

| Значение | Дела | Механика |
|---|---|---|
| `cards` (по умолчанию) | 1 | вертикальный таймлайн: латунная линия, карточки слева/справа, маркер с датой из текста; появление через IntersectionObserver, при обратном скролле уходят |
| `focus` | 2 | крупные даты, в фокусе блок у центра экрана, остальные приглушены и размыты, сбоку подпись; активный = ближайший к центру (функция scrollY) |
| `hline` | 3 | горизонтальная лента (HR Timeline): пузыри над/под линией с цифрой дня и днём недели, курсор «СЕЙЧАС», будущие события серые и проявляются по мере скролла; лента едет по вертикальному скроллу |
| `slides` | 4 | полноэкранные слайды с 3D-перелистыванием; секция N×100vh + sticky-сцена, кадр = функция scrollY; точки и стрелки скроллят к слайду |

Титул дела — над таймлайном. Дата для метки берётся из текста обстоятельства регуляркой
(`дд.мм.гггг` → «Месяц гггг» → год); нет даты — «Этап N» (в cards метка не показывается).

## Публикация

```
./deploy.sh "текст коммита"
```
Проставляет `?v=<метка>` на css/js (обход кеша Pages), копирует в `../legaldesign-trainer/`,
коммитит и пушит. Без версии новая `index.html` может прийти со старым `app.js`.

## Отладочный хук

`#case=0&side=defendant&picks=1,0,2&go=results&y=2400` — привести страницу к
нужному состоянию без кликов (для скриншот-прогонов). В обычной работе не участвует.

## Как добавить новый спор

Дописать объект в `window.CASES` (`js/cases.js`) по схеме из шапки файла
и ключ в `window.CASE_LAW`. Инварианты:

- ровно **три довода** на сторону, у каждого ровно **три варианта**;
- звёзды вариантов — набор `1, 2, 3` (правильный вариант не всегда первый);
- три исхода с порогами `min` по убыванию (`7` / `4` / `0` при сумме 3…9);
- `viz.kind` — один из семи рендереров; новых картинок рисовать не нужно.

Проверка данных без браузера:

```
node -e "global.window={};require('./js/viz.js');require('./js/cases.js');
let n=0;for(const c of window.CASES)for(const k in c.sides)for(const a of c.sides[k].args){
  const st=a.options.map(o=>o.stars).sort().join('');
  if(st!=='123')console.log('звёзды',c.id,k,st);
  for(const o of a.options){const s=window.Viz.render(o.viz);
    if(/undefined|NaN/.test(s))console.log('BAD',c.id,k,a.heading);n++}}
console.log('визуализаций:',n)"
```

## Правовая основа

Споры вымышлены, правовые позиции — нет. Карта позиций высших судов:
`../docs/laws/PRAKTIKA_arenda.md`.

## Известные ограничения

- Прогресс не сохраняется: обновление страницы начинает всё заново.
- Интро и фабула рассчитаны на прокрутку колесом/тачем; на очень низких
  экранах блоки идут плотнее.
- Сцены нарисованы под пейзажную ориентацию; в портретной здание суда
  частично уходит за края (slice), текст остаётся читаемым.
